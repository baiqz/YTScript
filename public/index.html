最近提取

功能

不只是「把字幕抠出来」

在做笔记、做二次创作、做内容研究之前，先把素材变成可编辑的文本。

多语言字幕轨道

视频里存在多少条字幕就列出多少条，手动字幕与自动字幕分别标注，可随时切换重新提取。

翻译成 100+ 语言

调用 YouTube 官方翻译轨道，直接把文稿转成中文、日文、英文等语言，无需外部翻译服务。

点击跳转播放

左侧播放器与文稿实时联动：点一行跳一段，播放到哪里文稿就高亮到哪里。

四种导出格式

纯文本贴进笔记，SRT / VTT 直接挂回剪辑软件，JSON 交给程序做结构化处理。

站内检索与段落模式

关键词高亮定位，逐句与段落两种视图切换，长视频整理成笔记更顺手。

纯本地、零依赖

所有请求都由你本机的 Node 进程发起，不经过任何第三方服务器，文稿不出本机。

使用说明

三步拿到文稿

  1. 1

    粘贴链接

    支持 watch、youtu.be、shorts、live、embed 等全部链接形态，也可以直接填 11 位视频 ID。

  2. 2

    挑选语言

    默认自动挑选最合适的字幕轨道；需要其他语言时在左侧下拉框切换，或选「翻译为」得到译文。

  3. 3

    带走文稿

    复制纯文本或带时间戳，也可以导出 TXT / SRT / VTT / JSON 存到本地。

关于网络：YouTube 在中国大陆不可直接访问。若提取失败，请先在右上角「网络状态」中填写本机代理地址 （如 http://127.0.0.1:7890），或使用 --proxy 参数启动服务。
常见问题

你可能想知道

为什么有的视频提不出文稿？

只有视频本身存在字幕时才能提取。如果 UP 主既没上传字幕、也没开启自动字幕，接口就取不到任何内容；此外私享视频、地区限制视频同样无法提取。

提示「接口限流（429）」怎么办？

YouTube 对「按需生成译文」做了较严的频率限制。稍等 10~30 秒再点一次通常即可成功；连续提取多个视频时建议放慢节奏。

翻译质量如何？

译文来自 YouTube 自带的翻译轨道，属于机器翻译，适合快速通读与检索，专业内容建议再人工校对。

文稿会经过第三方服务器吗？

不会。服务运行在你本机，请求由本机进程直接发往 YouTube，文稿只在你自己的浏览器与本地服务之间传递。

能批量提取多个视频吗？

当前版本一次处理一个视频，但保留了最近提取记录，点击即可快速回到之前的结果。批量能力可作为下一步扩展。

支持哪些导出格式？

纯文本 TXT、带时间戳 TXT、字幕格式 SRT 与 WebVTT，以及包含全部轨道与片段时间信息的 JSON。
